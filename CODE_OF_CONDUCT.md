# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep feedback about the work and not the person, and do not harass anyone.

Report problems to osntak@gmail.com. Reports are kept private.

이 프로젝트는 Contributor Covenant 2.1 을 따릅니다. 서로 존중하고, 의견은 사람이 아니라 작업에 대해 말해 주세요. 문제는 osntak@gmail.com 으로 알려 주세요.
